医師向け調査 mGAF質問ロジック・文言修正案

対象: 主治医が外来患者ごとにmGAF-SymptomとmGAF-Functionを付ける画面。現行フォームのP1を置き換える前のレビュー用案。

修正方針

1. 評価期間を固定

外来患者では「最近1か月で最も低かった状態」を基準にする。画面冒頭と各セクションに同じ前提を出す。

2. SとFを分ける

mGAF-Sは症状、mGAF-Fは社会機能として別々に採点する。共通する危険・衛生・緊急入院相当項目は一度だけ聞き、両方の採点に使う。

3. 上位重症度優先

重篤な危険、部分的な危険、ほぼ全領域の機能不全、重い症状/機能障害、中等度、軽度、最小症状の順に判定する。

4. 範囲ではなく内部点を保存

選択肢は得点帯で見せ、保存値は帯の低い値にする。画面には「保存点」と「得点帯」を両方表示する。

日本語版mGAFから使う原則

原則 質問票への落とし込み 理由
外来では最近1か月で評価する P1冒頭と各mGAFセクションに「最近1か月」を明記する。 現在の瞬間評価ではなく、外来患者の直近状態を反映するため。
もっとも低いと思われる得点で記録する 複数の得点帯に該当しうる場合は、より低い得点帯を優先する。 上位重症度から順に判定するロジックの根拠になる。
mGAF-Sは症状基準、mGAF-Fは社会機能基準 症状項目と社会機能項目を分け、共通する危険項目だけ再利用する。 症状が目立たない低機能群をmGAF-Fで拾うため。
31-50点台は該当項目数で得点帯が決まる Sは6項目、Fは4項目をチェックし、該当数から自動採点する。 医師に「領域数」を数えさせず、元スケールの項目数ロジックを保つ。
21点付近には独立した上位項目がある 自殺念慮への没頭、幻覚妄想に影響された行動、重度コミュニケーション障害を31-50点台より前に確認する。 31-50点台の項目数とは別に、1項目だけで21点相当となるため。

提案するP1全体構造

評価前提の確認

「この患者さんの最近1か月の状態を思い出してください。複数の状態がある場合は、最も低い状態で評価してください。」

理由: 元スケールの外来評価期間と「もっとも低いと思われる得点」を、回答開始前に固定するため。

共通の重篤項目

自殺・自傷、暴力/自傷行為、躁性興奮・焦燥・衝動性、身辺衛生、精神科緊急入院相当、医学的問題による身体的危機を、カテゴリごとに1画面1問の単一選択で確認する。

理由: 同じカテゴリ内で11-20点相当と1-10点相当が同時選択される矛盾を避け、現在の質問票と同じ操作感にするため。

mGAF-S: 症状プロファイル

重い精神症状、ほぼ全領域の機能不全に相当する症状、中等度症状、軽症状、最小症状を、1画面1問のウィザードで確認する。元mGAFが項目数で採点する31-50点帯のみ複数選択を許可する。

理由: 症状の有無と重症度を保存でき、後の患者因子解析にも使えるため。

mGAF-F: 社会機能プロファイル

主要機能障害4領域、続いて中等度/軽度/最小の機能低下を確認する。

理由: クロザピン適応相当判定では機能低下が重要で、症状と混ぜるとstably unwellを拾いにくくなるため。

スコア確認と分岐

mGAF-S、mGAF-F、低い方を表示し、mGAF-Fが41点以上の場合は患者単位の詳細質問を終了する。

理由: mGAF-F 40以下を反応性不良相当の操作的条件として使う現在の研究設計と整合させるため。

mGAF-Symptom 質問案

画面 S1 / 1問
自殺念慮・自殺企図・自傷行為について、最近1か月で最も近いものを1つ選んでください

同一カテゴリなので単一選択。選択に応じて、31-50点帯項目、21点項目、11-20点帯項目、1-10点帯項目のいずれかへ内部的に割り付ける。

画面 S2 / 1問
暴力行為・自傷行為について、最近1か月で最も近いものを1つ選んでください

同一カテゴリなので単一選択。時に危険なら11-20点帯、頻繁なら1-10点帯の該当項目として数える。

画面 S3 / 1問
躁病性興奮・焦燥・衝動性について、最近1か月で最も近いものを1つ選んでください

同一カテゴリなので単一選択。重度なら11-20点帯、極度なら1-10点帯の該当項目として数える。

画面 S4 / 1問
身辺の清潔・健康維持について、最近1か月で最も近いものを1つ選んでください

同一カテゴリなので単一選択。時にできないなら11-20点帯、持続的に不可能なら1-10点帯の該当項目として数える。

画面 S5 / 1問
精神病院への緊急入院の必要性について、最近1か月で最も近いものを1つ選んでください

同一カテゴリなので単一選択。かかりつけ医の指示で緊急入院なら11-20点帯、ただちになら1-10点帯の該当項目として数える。

画面 S6 / 1問
医学的問題による身体的危機について、最近1か月で最も近いものを1つ選んでください

同一カテゴリなので単一選択。身体的危機なら11-20点帯、急に重度の危険なら1-10点帯の該当項目として数える。

画面 S7 / 1問
精神病症状・コミュニケーションについて、最近1か月で最も近いものを1つ選んでください

同じ精神病症状・コミュニケーションのカテゴリとして単一選択。幻覚妄想/強迫儀式のみなら31-50点帯項目、幻覚妄想にかなり影響された行動または重度コミュニケーション障害なら21点相当。

画面 S8 / 1問
その他の重症の精神症状を認めますか 複数選択可

ここだけは元mGAFの31-50点帯が該当項目数で採点されるため複数選択を許可する。自殺・精神病症状カテゴリで31-50点帯項目が選ばれていれば、それも該当数に加える。

画面 S9 / 1問
中等度の精神症状がありますか。最も近いものを1つ選んでください

採点: 58-60、54-57、51-53点帯。例: 中等度の抑うつや不眠、中等度の反復思考や強迫観念がよくおきる、時に不安発作がおきる、感情が平板的で会話が回りくどい、食行動に問題がある、うつ病でないのに安全体重を下回る。

画面 S10 / 1問
軽症または最小限の精神症状について、最も近いものを1つ選んでください

採点: 軽症で心理社会的ストレスだけでは予測されない反応は61-70点帯、一過性で予測される反応は71-80点帯、精神症状がまったくないかほんの少しは81-90点帯。各帯の中では社会・職場・学校での問題の広がりにより下位帯を選ぶ。

mGAF-Function 質問案

Fへの自動反映
S1-S6の共通危険項目をmGAF-Fにも反映

自傷他害、身辺衛生、緊急入院、医学的問題による身体的危機は、mGAF-Sでカテゴリ別に単一選択した内容をmGAF-Fにも自動反映する。F側で同じカテゴリを再質問しない。

採点: 11-20点帯または1-10点帯の該当項目数として内部計算する。回答者にはスコア確認画面で反映項目を表示し、必要なら戻って修正できるようにする。

画面 F1 / 1問
F1. いくつかの重度の機能障害を認めますか

元mGAF-Fの21-50点帯は4項目の該当数で採点するため、この画面のみ複数選択を許可する。1項目44-50点帯、2項目37-43点帯、3項目31-36点帯、4項目21-30点帯。就労・就学していない場合は、家事、通所、デイケア、役割遂行、日中活動で判断する。

画面 F2 / 1問
F2. 中等度の社会・仕事・学業機能低下がありますか

採点: 58-60、54-57、51-53点帯。例: 友達が少ししかいない、同僚と衝突するなど。

画面 F3 / 1問
F3. 軽度または最小の機能低下

採点: 持続する軽度は61-70、一過性軽度は71-80、最小機能低下は81-90。

コメントへの対応案

コメント 対応する修正案 理由
「受動的な希死念慮」とは何か。 「受動的な希死念慮」という独自ラベルは使わず、日本語版mGAFの表現に合わせて「尋ねると希死念慮を認める」とする。必要時の補足として「自殺念慮への没頭や明確な準備はない」を添える。 日本語版mGAFの31-50点帯項目を活かし、21点相当の「自殺の考えに没頭している/準備している」と区別するため。
「死亡期待なしの自殺企図」はNSSIならその文言の方がよいのではないか。 日本語版mGAFの「はっきりと死にたいと望まない自殺企図」を基本文言にし、質問票上は「または自傷行為」を併記する。 NSSIだけに限定すると、軽度過量服薬や人前でのリストカットなど、元表の例示を狭める可能性があるため。
「死亡期待あり」は「希死念慮」の方が一般的ではないか。 日本語版mGAFの「はっきりと死ぬことを望んだ重度の自殺企図」を使う。 「死亡期待」という独自訳語を避け、元表の日本語表現に戻す。
身辺衛生の「なし」は「問題なし」か「保てる」ではないか。 「問題なく保てる」「時に最低限の身辺の清潔・健康維持ができない」「最低限の身辺の清潔・身体維持が持続的に不可能」にする。 「なし」だけでは何がないのか曖昧。元表の「時に」「持続的に」の違いを残す。
「身体的危険」とは何か。 「摂食・セルフケア等の問題に関連した身体的危険」とし、補足に「重度の拒食・過食、自発嘔吐、過度の下剤使用、脱水、管理不能な身体疾患など」を入れる。 mGAFの例示に沿って、精神状態やセルフケア低下に伴う身体危機だと分かるようにする。
「行動が妄想または幻覚に影響」と「幻覚・妄想・重い強迫儀式」の違いが分かりにくい。 前者を「幻覚・妄想にかなり影響された行動がある」、後者を「幻覚・妄想・重い強迫儀式があるが、行動が著しく支配されるほどではない」に分ける。 前者は21点相当の上位項目、後者は31-50点帯の重い症状領域として扱うため、行動への影響の有無で区別する。
「重い症状領域」「中等度症状」がつけづらい。 見出しを日本語版mGAFの「いくつかの重症の精神症状を認める」「中等度の精神症状がある」に戻し、項目は「判断能力に重度の障害がある」など元表の症状単位で選ばせる。 「領域」という採点者向け概念を前面に出さず、元スケールの症状項目に沿って回答できるようにする。
「判断の重い障害」は「重い判断」と読める。 日本語版mGAFの「判断能力に重度の障害がある」を使う。思考、気分、不安も「思考に重度の障害がある」「気分に重度の障害がある」「不安のために重度の機能障害がある」にする。 北川さんの読みづらさを解消しつつ、日本語版mGAFの文言から離れないようにする。
P9で「白血球数が足りない」症例をどう扱うか。 P9/P10に「医学的禁忌・検査値上の理由（白血球数・好中球数が基準を満たさない、または確認が必要）」を追加する。選択後の補助項目で「基準未満を確認済み」「過去低値・変動があり懸念」「直近値を把握しておらず確認が必要」を分ける。 担当症例をまとめて回答する場面では直近採血値を覚えていないことがあり、白血球数不足を確定理由としてだけ扱うと回答しづらいため。

P9理由項目の修正案

画面 P9 / 1問
クロザピン導入を積極的に検討しない、または保留する主な理由を1つ選んでください

主理由は1つのみ。白血球数・好中球数は「有害事象への一般的懸念」と分け、医学的に開始できない/確認が必要な理由として独立させる。

条件付き画面 P9a / 1問
P9で「医学的禁忌・検査値上の理由」を選んだ場合、最も近い状況を1つ選んでください

三澤先生の指摘どおり、主治医が一覧回答時に白血球数を把握していない可能性があるため、「基準未満を確認済み」と「未確認で保留」を分ける。

画面 P10 / 1問
副次的理由があれば選んでください 複数選択可

P10にも同じ「医学的禁忌・検査値上の理由」を追加する。主理由ではないが、導入判断に影響する場合を拾う。

文言修正一覧

対象 現行の問題 修正案 修正理由
P1冒頭 「現在のmGAF」だけでは評価期間が曖昧。 「最近1か月で最も低かった状態に基づいて、mGAF-SとmGAF-Fを別々に評価してください。」 外来評価の時間窓と最低点記録の原則を先に固定する。
症状入力 「現在みられる症状」は一時点評価に読める。 「最近1か月で該当した症状・状態」 外来患者では状態が変動するため、最近1か月の最重時点を拾う。
緊急入院 「精神科病院への緊急入院相当」がやや硬い。 「主治医判断では、ただちに精神科入院を要する状態」 回答者が臨床判断として答えやすく、入院先の制度差に左右されにくい。
身体的危険 精神症状評価なのに身体危険が唐突に見える。 「精神状態や摂食・セルフケアの問題に関連した急性の身体的危険」 拒食、過食、自発嘔吐、脱水など、元スケールの意図に近い範囲へ限定する。
精神病症状 「行動が妄想または幻覚に影響」と「幻覚・妄想・重い強迫儀式」の違いが分かりにくい。 21点相当は「幻覚・妄想にかなり影響された行動がある」、31-50点帯は「幻覚・妄想・重い強迫儀式があるが、行動が著しく支配されるほどではない」とする。 行動への影響の有無で上位重症度と重い症状領域を区別する。
重い症状領域 「判断、思考、気分、不安、幻覚/妄想/強迫、希死念慮を数えます」は説明が短い。 日本語版mGAFの「判断能力に重度の障害がある」「思考に重度の障害がある」「気分に重度の障害がある」「不安のために重度の機能障害がある」等をチェック項目として表示する。 医師が数を手計算しないで済み、元スケールの項目数ロジックと解析用の症状プロファイルを両方残せる。
mGAF-F主要機能 仕事/学業中心に読め、外来の無職・退職患者で迷う。 「仕事・学業・家事・日中活動の重い障害。就労・就学していない場合は役割遂行で判断。」 慢性期外来患者の機能低下を過小評価しないため。
スコア表示 低い値だけ表示すると得点帯が見えない。 「mGAF-F: 37（37-43点帯、主要機能障害2領域）」のように表示。 レビュー時に採点根拠が追跡しやすく、41点閾値との関係も説明しやすい。
早期終了 「mGAF-Fが41点以上」のみだと、なぜ終了するかが弱い。 「mGAF-Fが41点以上相当のため、本研究の反応性不良相当候補からは外れます。この患者の詳細質問は終了します。」 臨床的価値判断ではなく研究上の操作的分岐であることを明確にする。

採点ロジック仕様

領域 判定順 保存値 保存する補助情報
mGAF-S 重篤危険 → 一部危険 → ほぼ全領域機能不全症状 → 重い症状領域数 → 中等度 → 持続軽度 → 一過性軽度 → 最小症状 各得点帯の低い値 該当項目名、該当数、得点帯、最終ラベル
mGAF-F 共通重篤項目 → 共通一部危険項目 → 主要機能障害領域数 → 中等度機能低下 → 持続軽度 → 一過性軽度 → 最小機能低下 各得点帯の低い値 主要機能障害領域、得点帯、41点閾値判定

実装上の注意

mGAF-Fの37-43点帯は、保存値を37点にする限り研究上は40点以下として扱える。ただし画面表示では「37-43点帯」と明示し、閾値判定は保存値だけでなく採点帯もログに残す。
